## ✅ 一、日常 Git 操作流程（標準版）

```bash
git add .                         # 將所有變更加入暫存區
git commit -m "✨ feat: 你的更新說明"   # 寫下這次更新的意義
git push                          # 推送到遠端（如 GitHub）
```

你也可以只加指定檔案，例如：

```bash
git add main.py src/gui.py
```

## ✅ 二、如何查看當前 Git 狀態與歷史

| 操作           | 指令                          | 用途                       |
| ------------ | --------------------------- | ------------------------ |
| 查看變更（哪些檔案被改） | `git status`                | 顯示已修改、未追蹤的檔案             |
| 查看歷史紀錄       | `git log`                   | 顯示每次 commit 的 hash、訊息、時間 |
| 美化顯示 log（推薦） | `git log --oneline --graph` | 顯示簡短 commit 樹狀圖          |
| 查看差異（哪些地方改了） | `git diff`                  | 比較目前修改內容與最後一次 commit 差異  |
| 比較已加入暫存的變更   | `git diff --cached`         | 檢查 `git add` 後的變更內容      |
