# 社團檔案標準化命名與分類系統

## 簡介

本系統提供社團檔案標準化命名與分類功能，協助社團幹部有效管理檔案資源。

## 主要功能

- 檔案標準化命名（單一檔案與批次處理）
- 照片資料夾自動命名
- 檔案搜尋（基於正規表達式）
- 支援與 Google Sheet 連接

## 安裝方法

1. 確保已安裝 Python 3.6+
2. 安裝依賴套件：`pip install -r requirements.txt`
3. 執行主程式：`python main.py`

## 設定命名對照表

1. 使用「設定」頁籤載入命名對照表
2. 可使用 Excel 或 Google Sheet 作為數據源

## 命名規則

檔案命名格式：`[主分類代碼]_[細分類代碼]_[活動代碼]_[描述]_[日期].[副檔名]`

例如：`B_PL_HP_哈盆企劃書_2024-03-01.docx`

社團檔案命名與審核系統 – 功能需求說明（初版）
【產品目的】
打造一個具有良好 UI / UX 的檔案命名輔助系統，協助社團幹部針對社團活動檔案進行「半自動命名 + 人為審核 + 清晰管理」，提升分類效率與傳承品質。

【使用對象】
社團幹部（具基本電腦操作能力）

不需要具備程式背景

使用情境：期末彙整、活動後統整、評鑑前整理

【核心功能】
1. 圖形化使用介面（GUI）
提供「可視化操作」介面（非純命令列）

UI 美觀清晰（如：PyQt、Tkinter、Web 前端皆可）

可用拖拉或選單方式操作

2. 批次命名系統（半自動）
支援多筆資料一次命名

根據「分類代碼 + 活動代碼 + 用途 + 日期」自動產生檔名建議

每筆檔案都能手動編輯命名（有預覽欄）

3. 命名審核機制
所有檔案皆須經過人工確認才會命名

支援「逐筆確認」與「勾選後批次通過」兩種操作方式

每筆檔案都會記錄「是否審核過」狀態

4. 命名紀錄與追蹤
建立隱藏欄位（或後台 log）記錄：

檔案原始名稱

建議新名稱

最後實際名稱

審核人員（可選填）

審核時間

支援命名歷程查詢與導出（CSV / Excel）

5. 命名彈性與可修改性
即使自動命名後，也允許使用者手動修改

支援活動代碼對照表、細分類對照表快速選取（如下拉選單）

欄位輸入錯誤時自動提醒
