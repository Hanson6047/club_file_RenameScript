# 社團檔案標準化命名與分類系統

## 簡介

本系統提供社團檔案標準化命名與分類功能，協助社團幹部有效管理檔案資源。

## 主要功能

- 檔案標準化命名（單一檔案與批次處理）
- 照片資料夾自動命名
- 檔案搜尋（基於正規表達式）
- 支援與 Google Sheet 連接

## 安裝方法

1. 確保已安裝 Python 3.6+
2. 安裝依賴套件：`pip install -r requirements.txt`
3. 執行主程式：`python main.py`

## 設定命名對照表

1. 使用「設定」頁籤載入命名對照表
2. 可使用 Excel 或 Google Sheet 作為數據源

## 命名規則

檔案命名格式：`[主分類代碼]_[細分類代碼]_[活動代碼]_[描述]_[日期].[副檔名]`

例如：`B_PL_HP_哈盆企劃書_2024-03-01.docx`
